
# 🍽️ Zomato Sales Analysis Dashboard (Power BI)

## 📌 Project Overview

This project analyzes Zomato sales, customer behavior, city-wise performance, and order trends using Power BI. The dashboard provides actionable insights into sales performance, customer engagement, ratings, and geographical distribution of orders.

## 🎯 Objectives

* Analyze overall sales performance.
* Identify top-performing cities.
* Monitor customer activity and retention.
* Understand order trends across different years.
* Compare Veg, Non-Veg, and Other food categories.
* Track ratings and customer satisfaction.

## 📊 Dashboard Highlights

### Sales Performance

* Total Sales Amount: **₹989 Million**
* Total Quantity Sold: **2 Million**
* Total Ratings: **148K**
* Total Orders: **150K+**

### Year-wise Sales Trend

* 2017: ₹0.09 Billion
* 2018: ₹0.14 Billion
* 2019: ₹0.41 Billion
* 2020: ₹0.34 Billion

### Category-wise Sales

* Veg: ₹122 Million
* Non-Veg: ₹106 Million
* Others: ₹24 Million

### User Insights

* Total Users: 100,000
* Active Users: 78,000
* Gain Customers: 33,000
* Lost Customers: 11,700+

### Geographic Analysis

Top Performing Cities by Sales:

1. Tirupati
2. Electronic City, Bangalore
3. Baner, Pune
4. Raipur
5. Malviya Nagar

Zomato operates across **822 cities** and processed **150,281 orders**.

* Tirupati generated the highest sales revenue.
